# 标定板工坊

简体中文 · [English](README.md)

一款纯浏览器运行的标定板设计与导出工具。纸张、图案与排版几何全部以毫米存储，图案生成、排版与导出都在本地完成，应用不需要后端服务。

在线使用：<https://calib.qvleka.cn>。本仓库提供源码与部署说明。

**开发说明：**本仓库绝大部分源代码由 AI 生成。项目仍按开源软件的方式维护。

## 快速开始

环境要求：Node.js 22 或更新版本，以及 npm。

```bash
npm ci
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建（输出到 dist/）
npm run preview  # 本地预览生产构建
```

## 部署网址

默认执行 `npm run build` 即可部署到域名根目录或子目录：资源路径使用相对地址，无需修改源码中的域名。如果希望为搜索引擎生成绝对 canonical 网址与站点地图，可以在构建时设置 `SITE_URL` 为**自己的公开网址**；若部署在子目录，也要包含目录路径：

```bash
SITE_URL=https://example.com/calibration/ npm run build
```

设置 `SITE_URL` 后，构建时会据此设置资源路径、canonical、Open Graph 网址和 `dist/sitemap.xml`。部署在域名根目录时，`dist/robots.txt` 也会指向站点地图；部署在子目录时，请直接向搜索引擎提交站点地图，因为爬虫只读取域名根目录的 `robots.txt`。不设置 `SITE_URL` 时，不生成 canonical 或站点地图，`robots.txt` 只保留通用的允许抓取规则。请将 `dist/` 内容发布到你的部署网址；站点地图在公开可访问后才能帮助搜索引擎发现页面。

## 使用流程

1. **项目与纸张。** 选择纸张预设（A0–A6、Letter、Legal、Tabloid）或自定义尺寸，并可选**纵向或横向**。尺寸没有上限：20 mm 的标记小页和几米见方的地面标定板都能用；单边超过 10000 mm 时只提示、不阻止，因为常规打印与 PDF（单边 200 in / 5080 mm）已不适用。项目名会自动建议，之后仍可修改。未选中任何对象时属性栏显示页面设置；点击纸张空白处随时可以回到这里。
2. **标定板。** 选择图案并输入物理参数。图案是受保护图层：通过参数改几何，而不是拉伸。单码用「**Z 轴方向**」确定坐标系，ChArUco 可切换左上角方格（见[坐标约定](#坐标与识别器约定)）。
3. **图层。** 添加文字、矩形、圆形、直线、100 mm 校验线或 PNG/JPEG 图片，点击选中、拖动移动。名称可修改——在图层列表中双击、点悬停出现的铅笔按钮，或在属性栏编辑**图层名称**；重名会自动追加序号。每个标定板都可用箭头折叠子图层，也可一键**全部折叠/全部展开**。
4. **子图层。** 每个标定板都有 **XY 坐标轴**与**参数标签**；带编码标记的图案还会多一个 **ID 标注**子图层，把每个标记的编号标出来，**默认隐藏**，需要核对或出图时在图层列表打开即可。三者可独立显示、隐藏、移动、缩放，也可单独开启旋转。
5. **尺寸线。** 见下方[尺寸线](#尺寸线)。
6. **排版。** 排版标签页有两个子菜单：**工程图尺寸线**默认打开，**对齐工具**里是纸张对齐、边距与边到边距离。打开对齐工具时会自动关闭尺寸工具，画布即可选中和移动图层。
7. **导出。** PDF、SVG、150/300/600 DPI 的 PNG，或项目 JSON；可选尺寸线与打印比例补偿，在**图层**里插入的校验线会随图一起导出。

## 画布：草图式吸附拖动

在画布上拖动图层时，程序会像 CAD 草图一样推断关系，无需输入坐标：

- **对齐** —— 与任意可见图层的边缘、中心、贴边对齐，也包括纸张边缘与纸张中心；拖动过程中画出对齐参考线。
- **等距** —— 在两个相邻图层之间取等间距，或延续已有的间距节奏；两侧间距用同一个数值标注。
- **网格** —— 默认 1 mm，可切 0.5、2、5 mm 或关闭；用于推断关系未覆盖的位置，**推断出的关系优先于网格**。
- **实时读数** —— 底部状态栏显示坐标、四边距、当前吸附关系，以及图层移出纸张时的提醒。

吸附只写入位置数值，不会改变导出几何。

## 尺寸线

尺寸线只属于**排版**标签页。切到排版后尺寸工具**默认开启**，并弹出一条提示横幅——在画布上点一下（含空白处）或几秒后自动收起。按 **Esc**、点横幅按钮或工具栏标尺按钮即可退出工具，恢复拖动图层。其他标签页在项目已有尺寸线时会显示一个提示标签，点击即可跳到排版。

**创建。** 依次点击同一方向的两条边：图层边缘、图层中心线、纸张边缘都可拾取。第一次点击为参照，第二次为被标注对象；第二次点击后继续拖动即可把尺寸线拉到想要的距离，然后可继续标注下一条。

**编辑。** 单击尺寸线即选中并打开右侧属性栏（松开鼠标后仍保持选中；窄屏时属性栏自动滑出）：

- **测量值** —— 正负号表示被测边所在的侧向：正值为参照边的右侧／下方，负值为左侧／上方，因此同一个数字不会混淆两种可能，输入负值即可换到另一侧，也可点「**换到另一侧**」一键翻转；输入 **0** 即让两条边对齐。
- **联动求解** —— 其他尺寸测量的是同一批几何，因此程序会先找一种既满足本次修改、又不动其他尺寸的方案：被已有尺寸绑在一起的图层整体移动（例如标注到标定板的标题会跟着板走），量在图形自身上的尺寸先改尺寸再平移，使其他尺寸读到的边保持不动。有解时静默执行，并提示「已同时调整 N 个图层」。
- **冲突确认** —— 无解时先拦下并列出会跟着变的尺寸（含当前值与将变成的值），确认「**仍然修改**」（只移动被测对象并接受连带变化）或「取消」。
- **仅测量** —— 标定板与文字自身的尺寸只能读数；矩形、圆形、直线与图片会按数值改变宽高。
- **尺寸线位置与样式** —— 输入相对几何的偏移，或在画布上直接拖动（负偏移放到另一侧）；每条尺寸线可单独设置颜色，作用于线条、箭头、引线和数值。线条粗细与数值字号默认 0.5 mm 与 5 mm。
- **绘制样式** —— 尺寸线两端各有一个实心箭头（当跨度太短放不下两个箭头时会翻到外侧，避免压住数值），另有两条引线指示尺寸线的锚定位置。两者都可以逐条尺寸选择：箭头可选**实心**、**开口**、**建筑斜线**、**圆点**或不画；引线可选**自适应**、**虚线**、**细实线**、**只画两端短线**或不画。
- **引线不再横穿图面** —— 引线总是从朝向尺寸线的那一侧起画，把尺寸线拖到图层上方或左侧时不会再穿过图层；自适应样式在引线较短时保持虚线，一旦超过 30 mm 就断开成两端各一小段短线——标注相距很远的两条边时正是这种情况。
- **标注对象** —— 可改被测对象、参照对象（纸张或其他图层）与两条边。
- **显示与删除** —— 同一面板内完成；排版页的尺寸线列表也会列出每条尺寸线及其带符号数值。

尺寸工具开启期间，已有尺寸线仍可选中、双击输入数值或拖动调整位置。尺寸线保存在项目里，但只在排版标签页绘制。导出是否包含尺寸线由导出窗口决定。

画布工具栏的磁铁按钮开关智能吸附，旁边的下拉框选择网格步长。
标定板有校验问题时，点击底部状态栏中间的问题数量即可查看每条具体原因。

界面按可用宽度与界面字号选择布局：大屏同时显示工具栏、画布和属性栏；中等宽度保留左侧工具栏，属性通过按钮打开；手机让画布占满剩余高度，工具与属性分别按需打开为抽屉。默认字号下，分界为 1180 和 760 CSS px，调整界面缩放时分界同步变化。缩小窗口不会覆盖已经保存的侧栏宽度。顶栏的新建、导入、保存和导出在窄屏仍可使用，短窗口中的对话框可独立滚动。

顶栏的**界面缩放**可选择自动或 100%、110%、125%、150%、175%、200%；它影响文字和控件大小，标定板物理尺寸保持不变。画布初始处于**适应窗口**状态，会跟随窗口大小、侧栏宽度与纸张尺寸重新取景。手动放大、缩小或重置到 100% 后保留用户倍率；再次点击适应窗口按钮可恢复自动取景。放大后的纸张左侧与顶部仍可通过滚动访问。
缩放控件旁的颜色选择器用于设置界面主题色，选择会保存在当前浏览器中。点击顶栏的**恢复默认设置**可一次恢复默认主题色、界面缩放、侧栏宽度、浏览器默认语言、智能吸附与网格步长，并让画布重新适应窗口；当前项目及其图案位置不会改变。

## 坐标与识别器约定

纸张坐标以左上角为起点，向右和向下为正。几何一律由参数生成，不依赖预览像素或画布缩放。

**坐标轴标记。** XY 坐标轴锚定在原点角外侧、位于图案对角线的延长线上，箭头从该角落指向图案内部、不遮挡图案。改变原点角或旋转实际图案会改变识别器对布局的解释，识别端必须使用相同的布局与 ID 顺序。

**阵列类图案**的原点位于排列的某个角上，因此保留「坐标原点」选项；**单码**没有排列方向，原点固定在标记中心，坐标系改由「**Z 轴方向**」决定：

| Z 轴方向 | 坐标系 | 坐标轴位置 | 默认用于 |
| --- | --- | --- | --- |
| 指向标记外 | X 向右、Y 向上、Z 出纸面 | 左下角 | ArUco 单码（OpenCV 的标记系） |
| 指向标记内 | X 向右、Y 向下、Z 入纸面 | 左上角 | AprilTag 单码（官方方向标签在 AprilTag 库中的标记系） |

两者都是右手系，只相差绕 X 轴 180° 旋转，按识别端实际报告的约定选择即可。

**ChArUco** 左上角默认为 ArUco 标记，对应 OpenCV 4.6 之前的旧版排布（行数为偶数时等价于 `setLegacyPattern(true)`）；OpenCV 4.6 起默认左上角为黑色棋盘格，需要时把左上角方格改为**黑色棋盘格**。打印图案与识别端定义必须一致；修改起始 ID 时，识别端也须使用相同的标记 ID 序列。

**AprilGrid** 默认左下角为原点、起始 ID 为 0，ID 从左到右、由下到上递增，每个标签两格黑色边框，间隙交点带对称黑色角块。标准 Kalibr 实现使用 tag36h11，并直接按检测到的 ID 计算网格位置；非零起始 ID、其他 family 或起始角需要识别端适配。参见 [Kalibr 源码](https://github.com/ethz-asl/kalibr/blob/master/aslam_cv/aslam_cameras_april/src/GridCalibrationTargetAprilgrid.cpp)。

## 导出与打印精度

PDF 与 SVG 保留矢量几何，页面尺寸以毫米表示；PNG 按指定 DPI 栅格化。打印时选择 **100%／实际大小**，关闭“适合页面”缩放。在**图层**里插入 100 mm 校验线（长度恒为 100 mm，不可缩放，只能移动、改颜色与线宽），打印后测量它并输入实测长度做补偿；补偿后仍应确认图案位于纸张与打印机可打印区域内。

PDF 中非 ASCII 文字以图片嵌入，标记与几何图元仍是矢量。大尺寸 PNG 受浏览器内存限制，程序设有 1.2 亿像素保护上限。PDF 单边不能超过 200 in / 5080 mm，超出时请改用 SVG 或 PNG，这两种格式没有该限制。

## 项目文件与本地数据

当前项目自动保存在此浏览器的本地存储中。导出 JSON 可留存与转移；导入要求文件符合当前结构。不提供迁移，由 `version` 把关：

```json
{
  "version": 1,
  "name": "calibration-board-01",
  "width": 210,
  "height": 297,
  "layers": [],
  "dimensions": []
}
```

- 标定板图层需要 `pluginId`、`params`，以及 `children.axes`、`children.info`、`children.ids` 三项；每个子图层有 `visible`、`offsetX`、`offsetY`，可选 `title`（自定义名称）、`scale`、`rotation`。
- 标定板另外保存图层树的 `collapsed` 折叠状态；带 ID 的图案通过 `markers(params)` 提供 ID 标注位置。
- 尺寸线保存 `targetId`/`targetEdge`、`referenceId`/`referenceEdge`、`offset`、`visible`，可选 `lineWidth`、`fontSize` 与 `color`。数值带正负号：正值表示被测边在参照边的右侧或下方。
- 类型定义见 `src/core/model.ts`，导入校验见 `src/core/project.ts`；除特别注明外长度单位均为毫米。

应用不会把项目数据上传到服务器。

## 界面语言

界面提供中文与英文，顶栏的切换控件同时显示两个选项。首次访问会跟随浏览器语言——优先 `zh*` 显示中文、`en*` 显示英文，其他语言回落到英文；手动切换后会记住你的选择。
