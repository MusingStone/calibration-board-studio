This file records third-party dependencies and marker data provenance. The
hand-drawn geometric masthead icon was created for this project. The product
title is descriptive; this repository does not assert trademark rights in it.

## Runtime dependencies

These are bundled into `dist/` by the production build, directly or as their own
dependencies:

- React and React DOM — MIT License, https://react.dev
- Scheduler (used by React DOM) — MIT License, https://react.dev
- Lucide React — ISC License, https://lucide.dev
- pdf-lib — MIT License, https://pdf-lib.js.org
- `@pdf-lib/upng` — MIT License, https://github.com/Hopding/upng
- `@pdf-lib/standard-fonts` — MIT License, https://github.com/Hopding/standard-fonts
- pako — MIT License and Zlib License (it carries code derived from zlib),
  https://github.com/nodeca/pako

The full license texts are collected in `public/third-party-notices.txt`, which
Vite copies verbatim into the build output as `dist/third-party-notices.txt`, so
the notices travel with any deployed copy of the site. That file is generated by
`scripts/generate_notices.mjs` (`npm run notices`) from the installed packages
plus the fixed texts in `licenses/`; edit those sources rather than the output,
and re-run the script when a bundled dependency changes.

## Development dependencies

- Vite, esbuild, Rollup, PostCSS — MIT License
- TypeScript — Apache License 2.0
- `@types/react` and `@types/react-dom` — MIT License (type definitions only, not shipped)

No font is bundled: the interface and exported drawings use the system sans-serif stack (Arial and generic families). The interface icons come from Lucide React; the masthead icon and the calibration geometry are drawn in code.

predefined ArUco and AprilTag dictionaries by `scripts/generate_markers.py`.
